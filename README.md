# Ecommerce Web Application

A full-stack ecommerce web application built using Django and Django REST Framework.

## Features

- User Authentication
- Product Catalog
- Add to Cart
- Checkout System
- Order Tracking
- Admin Panel
- REST APIs

## Technologies Used

- Python
- Django
- Django REST Framework
- SQLite
- Bootstrap

## APIs

- /api/products/
- /api/orders/

## Setup Instructions

1. Clone repository
2. Create virtual environment
3. Install requirements
4. Run server
